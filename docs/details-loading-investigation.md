# Загрузка карточки аниме

Проверка 17 сентября 2026 года после 1.4.61. Запросов к сайту и источникам
для этой проверки не выполнялось; использованы локальные тесты.

## Что блокирует показ

Основные данные и варианты видео приходят одним запросом `/anime/{id}?need_videos=true`.
При открытии карточки приложение не проверяет медиассылки всех источников.
Полноэкранная загрузка зависит от `details`; комментарии, рекомендации и
история не являются условием показа основной карточки. Согласование личной
оценки использует локальное состояние, а не дополнительный сетевой запрос.

## Исправления

1. Восстановление профиля могло изменить контекст уже открытой карточки,
   сбросить её в Loading и сделать ответ старого запроса неактуальным.
   Повторно запускался только каталог на Home. Теперь при изменении контекста
   перезапускается загрузка видимой карточки. Проверка того же профиля не
   создаёт лишнего запроса; переход пользователя на другой экран сохраняется.
   Для уведомления со ссылкой-alias и ещё неизвестным числовым ID сохраняется
   исходная цель открытия. Старый ответ не может стереть alias новой карточки.

2. Даже для аниме без скачанных серий чтение offline-данных разбирало общий
   `index.json` со всеми карточками. Сохранение после API снова читало и
   переписывало его, добавляя туда онлайн-карточки без загрузок. Теперь сначала
   проверяется реестр загрузок выбранного аниме. Если зарегистрированных
   завершённых файлов нет, общий индекс не читается и не переписывается.
   Онлайн-метаданные остаются в отдельном content cache. Для настоящих загрузок
   сохраняются обновление карточки, нейтральность относительно аккаунта и
   синхронизация с регистрацией файлов. Старый индекс автоматически не удаляется.

Второй путь существовал и до последних изменений плеера. Его вклад в задержку
конкретного ТВ не измерен; исправление убирает подтверждённую лишнюю работу,
но не устанавливает скорость API или накопителя устройства.

## Проверка

Новый тест сохранения онлайн-карточки падал до исправления: создавался общий
offline-индекс. После исправления он не создаётся, а существующий индекс
других карточек не меняется. Зарегистрированные файлы остаются доступны после
обновления метаданных через другой экземпляр хранилища; незарегистрированные
файлы не удаляются и, как раньше, не считаются готовыми загрузками.

Для смены профиля проверяются ответ до и после смены контекста, отсутствие
повторного запроса при неизменном ID и уход на Home. Тесты вызывают production
helper и координатор операций; весь AuthStateRuntime с настоящим API и ТВ
этими тестами не моделируется.

Полный набор вместе с изменениями диагностики и восстановления CVH: 1318 тестов
без ошибок и пропусков, debug-сборка и компиляция release/instrumentation успешны.
